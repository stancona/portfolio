Overview

Stancona is a solo-built, production-grade full-stack web ecosystem for tabletop RPG communities. It combines a modern marketing site, a consumer mobile PWA, and an admin panel — all powered by a shared design system, AI-native development workflows, and self-hosted infrastructure.

Apex

Marketing site, blog, shop, design system showcase. Astro 7 + Preact islands.

Keep

Consumer PWA. Events, tickets with QR, league, offline-first. Preact + Vite.

App

Admin panel. RBAC, module system, command palette. Remix 3 + Preact.

Architecture

Surface Layer

Three distinct surfaces: Apex (public), Keep (consumer), App (admin). Each optimized for its audience.

Monorepo

Turborepo + pnpm catalog. 3 apps, 8 shared packages. Unified build, test, and deploy.

Authentication

OTP-based login, RBAC (5 roles), session tiers. Server-first, progressive enhancement.

Infrastructure

Coolify PaaS, Traefik reverse proxy, Cloudflare CDN + tunnel, PostgreSQL 18.

Design System

85+ components across 8 categories (Data Display, Navigation, Feedback, Actions, Data Input, Layout, Foundations, Overlays). Built with daisyUI 5 + Tailwind v4. Every component has automated SSR tests and fixture-based parity verification between Preact and Remix runtimes.

AI Orchestration

Stancona integrates AI at every layer: development (OpenCode), content generation, agent orchestration (Paperclip), and LLM gateway (LiteLLM). The system supports per-company isolation, budget enforcement, and provider fallback.

Paperclip

Agent orchestration control plane. Companies, budgets, heartbeats, audit. CEO: Hermes, CTO: OpenCode.

LiteLLM

Unified LLM gateway. 135+ providers, virtual keys, cost tracking, failover. Single API endpoint.

Hermes

Personal AI life assistant. Persistent memory, cron jobs, MCP tools. Connects to Paperclip and LiteLLM.
